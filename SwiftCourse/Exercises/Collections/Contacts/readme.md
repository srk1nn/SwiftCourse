# Contacts

### Описание

Программа для телефонного справочника. В справочнике хранится информация о пользователях, где ключ — это имя, а значение — номер телефона.  
  
Нужно написать код, который:
- добавляет телефон (`phoneToAdd`) для имени (`nameToAdd`)
- удаляет телефон по имени (`nameToRemove`) из справочника
- проверяет есть ли номер по имени (`nameToCheck`). Если номер есть, то записывает его в `checkedPhone`, если нет, то записывает в `checkedPhone` слово «Нет»

### Задание

Решение нужно написать в файле Contacts. Для решения используй переменные, которые доступны внутри скобок:
- `handbook` – справочник / словарь. Добавлять и удалять номера нужно из него. *Его можно изменять* (тип [String: String]);
- `nameToAdd` – имя для добавления в справочник (тип String);
- `phoneToAdd` – номер для имени из `nameToAdd` (тип String);
- `nameToRemove` – имя человека для удаления из справочника (тип String);
- `nameToCheck` – имя для проверки, есть ли такой человек в справочнике (тип String);
- `checkedPhone` – переменная, в которую нужно присвоить номер человка с именем `nameToCheck` (тип String).  
  
P.S. Не создавай переменные с такими же названиями.
