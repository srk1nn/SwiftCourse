# Uniques

### Описание

При объединении данных из разных источников некоторые значения оказались задублированными. Нужно написать программу, которая удаляет все дубликаты из массива.  

### Задание

Решение нужно написать в файле Uniques. Для решения используй переменные, которые доступны внутри скобок:
- `values` – массив с дубликатами (тип [Int]);
- `uniques` – переменная, в которую нужно присвоить ответ. Массив, который НЕ должен содержать дубликатов (тип [Int]).  
  
P.S. Не создавай переменные с такими же названиями.

### Пример
Для массива `["iPhone", "iMac", "iPhone"]` ответ должен быть `["iPhone", "iMac"]`.  

### Проверка

Для проверки запусти тесты CollectionsTests/Uniques

### Дополнительно

Попробуй решить это задания двумя способами
- с использованием цикла `for-in` и `Set`
- без использования циклов, только через `Set`. 

### Подсказка

Для решение через циклы можно перебрать все элементы массива и положить их в отдельный Set. Set возьмет только уникальные значения. Останется лишь Set переложить обратно в Array. 

Для решения только через `Set` можно воспользоваться преобразованием массива в множество. Оно происходит также как и преобразование примитивных типов `let newSet = Set(values)` и обратно `let newArray = Array(newSet)`.
