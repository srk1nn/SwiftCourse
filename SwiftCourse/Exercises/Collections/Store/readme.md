# Store

### Описание

В магазине инвентаризация. Задача — подсчитать количество конкретного товара на складе. Программа принимает массив товаров и название нужного товара, а затем считает его количество в массиве.  

### Задание

Решение нужно написать в файле Store. Для решения используй переменные, которые доступны внутри скобок:
- `products` – товары на складе (тип [String]);
- `name` – название интересующего товара (тип String);
- `total` – переменная, в которую нужно присвоить ответ. Количество товара name в массиве products (тип Int).

P.S. Не создавай переменные с такими же названиями.

### Пример
Для массива `["iPhone", "iPad", "iPhone"]` и товара `"iPhone"` ответ должен быть 2.
Для массива `["iPhone"]` и товара `"iPad"` ответ должен быть 0.
Для пустого массива и товара `"iPad"` ответ должен быть 0.
