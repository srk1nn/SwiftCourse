# Order

### Описание

В нашем магазине теперь можно оформлять онлайн-заказы. Чтобы отправить товар клиенту, нужно определить его местоположение на складе. Номер полки соответствует индексу товара в массиве, поэтому требуется найти индекс первого подходящего товара.     

### Задание

Решение нужно написать в файле Order. Для решения используй переменные, которые доступны внутри скобок:
- `products` – товары на складе (тип [String]);
- `name` – название интересующего товара (тип String);
- `productIndex` – переменная, в которую нужно присвоить ответ. Индекс первого name в массиве products (тип Int).  
  
Если нужного элемента нет в массиве, то ответ должен быть -1.  
  
P.S. Не создавай переменные с такими же названиями.

### Пример
Для массива `["iPad", "iPhone", "iMac", "iPhone"]` и товара `"iPhone"` ответ должен быть 1.  
Для массива `["iPhone"]` и товара `"iPhone"` ответ должен быть 0.  
Для пустого массива и товара `"iPhone"` ответ должен быть -1.  

### Дополнительно

Попробуй решить это задания двумя способами: через цикл `for in` и через `while`. 

### Проверка

Для проверки запусти тесты CollectionsTests/Order 

### Подсказка

Для решения нужно итерироваться не по элементам массива, а по индексам. Индексы массива – это диапазон значений – `0..<products.count`.  
    
`count` – это свойство массива (одна из его возможностей), которое возвращает количество элементов в массиве.  
  
Когда первый элемент найден, нет смысла продолжать поиск, поэтому выходи из цикла с помощью `break`.
