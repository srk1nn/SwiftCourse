# Friends

### Описание

В приложение социальной сети нужно добавить новую возможность. Когда пользователь заходит на страничку к своему другу, он хочет видеть «Общих друзей». То есть список друзей, которые есть и у него, и у того, чью страницу он просматривает. Нужно написать код, который находит пересечение в обоих списках – это идеальная задача для множеств!

### Задание

Решение нужно написать в файле Friends. Для решения используй переменные, которые доступны внутри скобок:
- `friends` – список друзей пользователя (тип `Set<String>`);
- `otherFriends` – список друзей пользователя, к которому мы зашли на страничку (тип `Set<String>`);
- `mutualFriends` – переменная, в которую нужно присвоить ответ. Список общих друзей (тип `Set<String>`).
  
P.S. Не создавай переменные с такими же названиями.

### Дополнительно

Используй специальный метод для работы с множествами у типа Set.
