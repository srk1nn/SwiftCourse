## Циклы в Swift
Циклы используются для:
- Повторения действий заданное количество раз.
- Перебора элементов массива, словаря или других коллекций.
- Выполнения действий до тех пор, пока выполняется определённое условие.

В Swift есть три основных типа циклов:
1. **`for-in`**: выполнение заданное количество раз (перебор элементов коллекции).
2. **`while`**: выполнение до тех пор, пока условие истинно.
3. **`repeat-while`**: как `while`, но условие проверяется после первой итерации.

---

## Цикл `for-in`

**Перебор массива**
```swift
let fruits = ["Яблоко", "Груша", "Банан"]

for fruit in fruits {
print("Я люблю \(fruit)")
}

// Вывод:
// Я люблю Яблоко
// Я люблю Груша
// Я люблю Банан
```

**Работа с диапазоном чисел**
```swift
for number in 1...5 {
print("Число: \(number)")
}

// Вывод:
// Число: 1
// Число: 2
// Число: 3
// Число: 4
// Число: 5
```

**Перебор словаря**
```swift
let scores = ["Анна": 10, "Игорь": 20, "Лиза": 15]

for (name, score) in scores {
print("\(name) набрал \(score) очков")
}

// Вывод:
// Анна набрал 10 очков
// Игорь набрал 20 очков
// Лиза набрал 15 очков
```

## Цикл `while`

**Пример: Счётчик**
```swift
var counter = 1

while counter <= 5 {
print("Счётчик: \(counter)")
counter += 1
}

// Вывод:
// Счётчик: 1
// Счётчик: 2
// Счётчик: 3
// Счётчик: 4
// Счётчик: 5
```

## Цикл `repeat-while`

**Пример**
```swift
var number = 1

repeat {
print("Число: \(number)")
number += 1
} while number <= 3

// Вывод:
// Число: 1
// Число: 2
// Число: 3
```

## Управление циклами

- **`break`**: Немедленно завершает выполнение цикла.
- **`continue`**: Пропускает текущую итерацию и переходит к следующей.

```swift
for number in 1...10 {
if number == 5 {
print("Цикл завершён на числе \(number)")
break
}
print(number)
}

// Вывод:
// Число: 1
// Число: 2
// Число: 3
// Число: 4
// Цикл завершён на числе 5
```

```swift
for number in 1...5 {
if number == 3 {
continue  // Пропустим число 3
}
print(number)
}

// Вывод:
// Число: 1
// Число: 2
// Число: 4
// Число: 5
```
