# Loyalty

### Описание

В магазине существует программа лояльности, где каждому клиенту присваивается уровень. Уровень хранится в словаре, где ключ — имя клиента, а значение — его уровень. По уровню определяется размер скидки клиента.  

Всего уровней 3:
- Бронзовый – скидка 5 %
- Серебряный – скидка 10 %
- Золотой – скидка 20 %  

Нужно для определенного клиента вычислить размер скидки, который ему положен. Если у клиента нет уровня (его нет в словаре), то считаем, что размер скидки – 0 %.

### Задание

Решение нужно написать в файле Loyalty. Для решения используй переменные, которые доступны внутри скобок:
- `levelByClients` – словарь, где ключ — имя клиента, а значение — его уровень (тип [String: String]);
- `name` – имя клиента, для которого нужно вычислить размер скидки (тип String);
- `discount` – переменная, в которую нужно присвоить ответ. Размер скидки (тип Int).

P.S. Не создавай переменные с такими же названиями.
